Changes from Figma

Made so every screen meets the project rules: text 14px or larger, 4.5:1 for text, 3:1 for controls.

  • Muted text #7a6e64 → #716559. The Figma colour is 4.4:1 on the cream page.
  • Step numbers: white on amber is 2:1, so the numbers are dark brown.
  • Placeholder #c8bea8 (1.8:1) → muted text colour.
  • Step label 13px → 14px.
  • Input, radio and switch borders use #8a7e72 so the controls are visible (the Figma sand border is 1.3:1).
  • Selected tiles and pills get a tick, so the choice doesn't rely on colour alone.
